# 광주 도심 관광 추천 요구사항

- 현재 위치 또는 수동 위치에서 반경 3/5km의 관광 후보를 최대 5곳 제안한다.
- 지원 구역은 북위 35.115~35.180, 동경 126.885~126.955의 시연 경계다.
- 선택, 길찾기, 건너뛰기, 방문 완료를 구분하고 방문·제외 장소를 재추천하지 않는다.
- 방문 완료 후 현재 위치 확인 실패 시 사용자 확인을 거쳐 직전 방문지를 기준으로 사용한다.
- 운영정보가 누락되거나 모호하면 확인 필요로 표시한다. 확인된 방문 불가 장소는 제외한다.
- 실제 관광정보의 출처·갱신일·조회 시점을 표시하고 데이터 부족이나 장애를 숨기지 않는다.
- 정밀 위치와 인증키는 분석 로그·프론트엔드·Git에 저장하지 않는다.
- 예약, 전국 최적화, 학습 모델, 자동 방문 감지는 범위에서 제외한다.
