# 갈랑가? UI

Figma Make 참의자의 원본 React/CSS를 읽어 기존 아이보리·청록·네이비 디자인과 5단계를 로컬에 적용한다.
여행지 뽑기 → 지역 비교 → 일정 초안 → 혜택 확인 → 준비 체크리스트를 제공한다.

- 실제 /api/team/benefits를 연결하고 로딩·오류·빈 결과를 구분한다.
- 원본 예시 금액과 자격 판정은 사용하지 않는다. 공고 검증 전 금액은 확인 필요로 표시한다.
- 관광지 API 미연결 상태의 일정은 초안으로 명시한다.
- 입력과 체크는 탭의 sessionStorage에 보관하며 서버에 전송하지 않는다.
- 지역 비교, 공식 링크, 뒤로가기, 날짜 입력, 모바일 CTA를 동작시킨다.
- 글자 크기·대비·터치 영역·키보드 포커스를 개선한다.

검증: TypeScript/Vite 빌드, API 로딩, 검색·비교·5단계 전환·모바일 넘침.

## 광주·전남 새총 지도

- 첫 화면의 취향·거주지·인원 등 사전 입력 폼을 제거하고 광주·전남 지도와 새총으로 대체한다.
- 노란 탄환을 마우스/터치로 아래로 당겼다 놓는다. 방향에 따라 반대 방향으로 발사하며, 놓는 순간 비행 거리와 소폭의 좌우 편차를 무작위로 정한다. 당긴 길이로 비행 거리를 정하지 않는다.
- 당기는 동안 짧은 방향 화살표만 보여준다. 정확한 착지점·당김 비율·조준 지역은 표시하지 않는다. 착지점에서 가장 가까운 현재 연결 지역을 선택한다. 같은 방향도 다른 결과가 나올 수 있다.
- 광주 5개 구·전남 22개 시군 전체를 독립된 여행지 목록으로 둔다. 혜택 유무와 무관하게 모두 직접 선택·새총 도달이 가능해야 한다.
- 다시 당기기, 지역 직접 선택, 방향키 조준+Enter 발사, Escape 취소를 제공한다. Pointer capture와 pointercancel/lostcapture를 처리하고 중복 발사를 막는다.
- 지도는 광주·전남 경계만 로컬 SVG로 표시하고 출처를 명시한다. 별도 지도 API 키·라이브러리가 필요하지 않다.
- 신청 마감 지역도 여행지로 선택될 수 있으며 결과에 현재 수집된 상태를 표시한다. API 장애나 혜택 미연결 상태에서도 새총·직접 선택을 제공한다.
- 날짜·여행 유형·인원·거주지 등은 지역 선택 이후 필요할 때 여행 정보 수정에서 변경한다. 취향은 수집하지 않는다.
- reduced-motion에서는 비행 애니메이션만 생략한다. 조준/결과는 유지하며 언마운트 시 animation frame을 취소한다.

## 증빙 자료 정리

- 준비 체크리스트에서 방문 사진·결제 영수증·숙박 증빙 이미지를 분류해 추가한다.
- 여러 파일 선택과 끌어놓기, 이미지 미리보기, 장소·사용일·금액·메모 수정, 삭제를 지원한다.
- JPG/PNG/WebP만 허용하며 파일당 8MB, 최대 12개, 합계 32MB로 제한한다. 손상 파일과 중복 선택은 안내한다.
- 파일은 브라우저 메모리에만 보관하고 서버로 전송하지 않는다. 지역·여행일별로 분리하며 단계 이동 시 유지하지만 새로고침 시 사라진다. 자료가 있으면 페이지 이탈 경고를 제공한다.
- 사용자가 입력한 영수증·숙박 금액만 합산한다. 환급액이나 심사 결과로 표시하지 않는다. OCR은 이번 범위에 포함하지 않는다.
- 미리보기 후 원본 이미지가 포함된 독립 HTML 정리본을 내려받는다. 정리본은 브라우저에서 열고 인쇄할 수 있으며 지자체 공식 양식이나 실제 제출을 대신하지 않는다.
- 검증: 파일 형식/용량/중복, 문서 출력 이스케이프, 금액 합산, 빌드, 업로드/수정/삭제/미리보기/다운로드 및 모바일 표시.

## 지역별 축제 추천

- 선택 지역의 공식 축제 일정·출처·수집 시각을 표시한다. 여행일과 겹치는 행사 우선, 다른 일정·종료·취소 행사는 구분한다.
- 모든 지역에 추천 영역을 제공하고 확인된 축제가 없으면 빈 상태와 공식 목록을 안내한다. 개최일과 위치를 추측하지 않는다.
- 문체부 공개 목록을 저속 수집해 별도 SQLite 테이블에 보관한다. 새 테이블만 추가하며 기존 데이터는 보존한다. 실패한 수집은 기존 기록을 지우지 않는다.
- 오래된 수집은 재확인 필요로 표시한다. API 로딩·오류·빈 결과를 구분한다.

## 지도 전체 화면 (2026-10-30)

- 첫 화면은 브라우저 전체 폭·높이의 지도이며 큰 제목·소개·단계 안내 영역을 제거한다.
- 로고·이용 안내·지역 선택·혜택 목록만 지도 위에 배치한다. 새총과 짧은 당김 안내는 화면 안에 유지한다.
- 지역 선택 메뉴와 결과 카드는 지도 위에 표시한다. 모바일에서도 스크롤 없이 탄환을 당길 수 있어야 한다.
- 기존 프론트 브랜치와 팀 확인용 Vercel 주소에 반영한다.
